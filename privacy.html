Ashish Uploader

Privacy Policy

Last updated: 5 November 2026

Summary

Ashish Uploader is a personal tool that runs on its operator's own computer. It has no servers, no database, no analytics and no third-party services. Nothing is sold or shared.

What data the app handles

When you authorize the app with TikTok, it receives:

  • Basic profile information (open ID, display name and avatar) through the user.info.basic scope, used only to confirm which account is connected.
  • An access token and a refresh token, which let the app post on your behalf through the video.publish and video.upload scopes.
  • Your creator settings returned by TikTok (available privacy levels, interaction settings and maximum video duration), used only to build each post correctly.

The app also reads the video files and captions you choose to post, and sends them only to TikTok.

Where data is stored

Tokens are stored in a local file on the operator's own computer, readable only by that user account. They are never uploaded anywhere other than to TikTok's own API when making requests. Video files stay on the local machine apart from the upload to TikTok.

This website

This site is static and hosted on GitHub Pages. It sets no cookies and runs no tracking. The OAuth callback page displays the one-time authorization code in your own browser so you can copy it into the local tool; the code is not sent to any server by this site. GitHub may log standard request data as described in the GitHub Privacy Statement.

Retention and deletion

Tokens are kept until access is revoked or the local token file is deleted. You can revoke access at any time in the TikTok app under Settings, Security, Manage app permissions, after which the stored tokens stop working.

Children

The app is not directed at children and is used only by its adult operator.

Contact

Privacy questions can be raised through the project's GitHub issues page.
